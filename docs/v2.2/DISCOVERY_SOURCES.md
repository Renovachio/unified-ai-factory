# Discovery source policy

Initial candidates (not preapproved):
- Local user-selected Claude Code skill roots and project `.claude/skills/`.
- User-provided ZIP archives / directories.
- https://agentskills.io/ (format and registry discovery when available).
- https://github.com/anthropics/skills (individual license/provenance review).
- https://github.com/product-on-purpose/pm-skills (candidate PM corpus; independently verify actual contents and rights).
- https://github.com/calikasten/product-management-agent (candidate agent design reference; independently verify actual contents and rights).
- Approved organization repositories and pinned GitHub references.

These are **search/discovery candidates**, not security endorsements, install authorizations, or promises of compatibility. Use read-only metadata first, pin exact refs/hashes, verify licenses before code reuse, and quarantine imported content. Do not assume an installed skill in Claude web is readable from a local filesystem.
