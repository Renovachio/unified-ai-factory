# AGT-004 — Local model adapter

**Milestone:** M3  
**Dependencies:** AGT-001,RUN-001  
**State:** NOT_STARTED

## Scope and concrete deliverables
Implement local/self-hosted inference adapter with bounded context, outputs, health and cancellation.

Expected outputs: production TypeScript implementation in the target module(s) described by `ARCHITECTURE.md`, unit/contract/integration tests appropriate to the boundary, minimal operator documentation, migration notes if needed, and a human-readable evidence report. The precise file tree is established when FND-001 creates the monorepo; do not invent new packages when a designated package already exists.

## Procedure
1. Confirm dependencies are ACCEPTED in `PROGRESS.md`, and verify a clean branch. If blocked, record reason and stop.
2. Review `AGENTS.md`, `SECURITY.md`, `CONTRACTS/README.md` and the relevant blueprint sections. List intended files and tests in the task evidence before changing code.
3. Implement the smallest complete vertical slice with schema validation, explicit failure modes and tests. Mock external providers before live credentials.
4. Run package validation (`python3 scripts/validate_package.py`), relevant unit/contract tests, lint/typecheck/build, and any end-to-end scenario touching this change.
5. Capture exact commands, results, candidate commit SHA, failed/retried checks, remaining risk and reviewer approval in `evidence/AGT-004/report.md`.
6. Mark task ACCEPTED only if all criteria pass and a reviewer/operator authorizes the result; otherwise BLOCKED.

## Verification and acceptance
- Baseline objective: offline inference and same adapter contract suite pass.
- Specific required checks: Offline execution (egress denied) passes shared contract tests and validated schema outputs.
- No regression of `SECURITY.md` hard rules, cross-job isolation, authorization or no-paid-model-inference constraints.
- Contract outputs validate against `CONTRACTS/`; no skipped/ignored failures.

## Stop and escalation conditions
- No cloud hosted metered inference endpoint.
- Missing provider authorization, secret handling uncertainty, failed isolation, ambiguous license, stale checks, or unauthorized external access must block the task.
- Do not modify acceptance requirements to make failing tests pass. Do not merge or deploy without approved policy.

## Evidence template
`evidence/AGT-004/report.md`: status, dependency commits, files changed, tests/commands and exit codes, validated artifact hashes, security findings, candidate SHA, reviewer, sign-off and next task.
